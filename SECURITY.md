# Política de segurança

## Como relatar uma vulnerabilidade

Não abra issue pública. Use o relato privado do GitHub: aba **Security** do repositório → **Report a vulnerability**. Descreva o problema, a versão afetada e, se possível, os passos para reproduzir.

A correção e a data de divulgação são combinadas com quem relatou.

## Versões cobertas

O projeto está na Fase 0 e ainda não tem versão estável. Até a 1.0, só a versão mais recente da branch `main` recebe correções.

## Escopo

Interessam em especial: escalada de privilégio pelo `vigiahost-executor`, contorno da política do executor, falhas na interface web e na API, e qualquer forma de um usuário de hospedagem influenciar o resultado das verificações.
